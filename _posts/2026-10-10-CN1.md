An IP address is split into two parts: the **NID** (Network ID) and the **HID** (Host ID). Setting the HID bits to special values gives addresses with special meanings.

## Special addresses

| NID | HID | Meaning |
|-----|-----|---------|
| Valid | All 0's | **Network ID** of the whole network |
| Valid | All 1's | **Direct broadcast address** |
| All 1's | All 1's | **Limited broadcast address** |
| All 1's | All 0's | **Subnet mask** |

- **Network ID (valid NID, HID all 0's):** identifies the entire network. Example: `134.54.0.0` is a Class B network address.
- **Direct broadcast (valid NID, HID all 1's):** lets an *external* network send data to every host in this network. Example: `134.54.255.255` is the direct broadcast address for the `134.54.0.0` network.
- **Limited broadcast (all 1's, all 1's):** always `255.255.255.255`. A host on the *internal* network puts it in the destination IP address to send a packet to every host on its own network. Routers do not forward it.
- **Subnet mask (all 1's NID, all 0's HID):** used to separate the NID from the HID (see below).

---

## Network mask (default subnet mask)

The network mask helps identify which part of an address is the NID and which is the HID.

| Class | First octet range | Default mask |
|-------|-------------------|--------------|
| A | 1 – 126 | `255.0.0.0` |
| B | 128 – 191 | `255.255.0.0` |
| C | 192 – 223 | `255.255.255.0` |

---

## Finding the network address

Perform a bitwise **logical AND** between the IP address and the subnet mask for its class.

**Example:** `200.200.200.99`

1. The first octet is `200`, which is in the range 192 to 223, so this is a **Class C** address.
2. The Class C subnet mask is `255.255.255.0`.
3. Apply bitwise AND:

```
    200.200.200.99
AND 255.255.255.0
-------------------
=   200.200.200.0
```

So `200.200.200.0` is the **network address**.
