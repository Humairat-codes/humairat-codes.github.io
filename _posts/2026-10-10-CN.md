# Types of communication
- Unicast (1:1)
- Broadcast (1 : all)
- Multicast (1:mnay)
- Anycast (1:nearest)
  
---

# **Unicasting**
- A direct, one-to-one communication between a single sender and a single receiver.
- Data packets are addressed to a specific destination IP address. If 50 people are streaming a movie from Netflix, the server establishes 50 separate unicast streams, sending unique data packets to each user.
- Use Case: Most everyday internet traffic (browsing websites, checking email, downloading files, SSH connections).


 # **Broadcasting**
- What it is: A transmission from a single source to every device on a given local network segment (LAN).
- How it works: The sender uses a special broadcast IP address (like 255.255.255.255). Every device on the network receives and processes the packet, whether they want it or not. Routers typically block broadcasts from crossing over to other networks to prevent network congestion (broadcast storms).
- Use Case: Address Resolution Protocol (ARP) looking up a MAC address, DHCP discovery messages when a device first connects to Wi-Fi.

# **Multicasting**
- What it is: A transmission from a single source to a specific group of interested receivers.
- How it works: Instead of flooding the whole network (broadcasting) or sending individual copies to everyone (unicast), the sender transmits a single data stream to a special multicast IP address. Devices must explicitly "join" the multicast group to receive the traffic. Switches and routers efficiently copy the data only down paths where receivers are listening.
- Use Case: IP television (IPTV), live video streaming, online gaming lobbies, and video conferencing where one feed goes out to multiple participants.

# **Anycast**
- What it is: A transmission where data from a single sender can go to any one of several destination nodes, but the network automatically routes it to the closest or best one topologically.
- How it works: Multiple servers around the world share the exact same IP address. Using routing protocols like BGP, the internet router automatically delivers a user's request to the server node that has the shortest path or lowest latency.
- Use Case: Content Delivery Networks (CDNs like Cloudflare or Google) and Domain Name System (DNS) root servers so you always query the nearest server for fast response times.
