## What is data collection?

**Data collection** is the process of gathering data from sources to be used in analysis and problem solving.

Sources can be hospital EHRs, banks, CSV files, APIs, websites, and more.

### Need for data collection

- Ensures you have the **raw material for decision making**
- Helps identify **trends, patterns**, etc.
- Lays the **foundation for data quality**, since poor collection leads to inaccurate results

**Example:** You run an online e-commerce website and want to track the number of customers who add something to their cart every day. This data won't appear magically. A data collection system is set up to collect it and place it in a database for future analysis.

---

## Data pipelines

A **data pipeline** is a system that automates the movement of data from one place to another, often transforming it on the way.

**Example: ETL pipeline (Extract, Transform, Load)**

```
Sources  →  Extract  →  Staging area  →  Transform  →  Load  →  Data warehouse
```

1. Data comes from various sources.
2. The data is **extracted** and temporarily stored in a **staging area**, where **transformation** takes place.
3. The data is then **loaded** into the **data warehouse** for persistent storage.
4. Data analysts and scientists use the prepared data from the warehouse to analyze trends and patterns and make informed decisions.

---

## What is data cleaning?

**Data cleaning** is the process of identifying and fixing issues (**dirty data**) in your data to make sure it is **consistent, accurate, and complete**.

**Example:** `John Doe`, `J Doe`, `John D`, etc. all refer to the same person, but the data isn't consistent. Data cleaning is needed to make it consistent.

### Why clean data?

- **Ensures accuracy:** decisions based on bad data can be inaccurate
- **Improves efficiency:** clean data is easier to analyze
- **Builds trust:** stakeholders need confidence in the data to act on the insights you get from it

---

## Data cleaning cycle

1. Importing data
2. Merging data sets
3. Rebuilding missing data
4. Standardization
5. Normalization
6. De-duplication
7. Verification and enrichment
8. Exporting data
9. **Repeat**
