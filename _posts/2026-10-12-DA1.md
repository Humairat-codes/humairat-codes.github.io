## What are file types?

A **file type** refers to the format in which data is stored in a file.

Each file type is designed for a specific purpose, depending on the type of data it holds and how that data will be processed or shared.

## Overview

| Category | Structure | Examples |
|----------|-----------|----------|
| Text files | Plain text, unformatted or tabular | `.txt`, `.csv` |
| Structured files | Predefined rows and columns, or hierarchical formats | `.xlsx`, `.db` |
| Semi-structured files | Loose structure, complex data relationships | `.json`, `.xml` |
| Unstructured files | No specific format, raw or multimedia data | `.png`, `.mp4` |
| Big data and specialised files | Designed for large-scale data | `.parquet` |

---

## Text files

- Simple files where data is stored in **text form**, using unformatted or tabular data.
- **Examples:** `.txt`, `.csv`

## Structured file types

- Files stored in a **predefined structure**, in rows and columns or hierarchical formats.
- **Examples:** `.xlsx`, `.db`

## Semi-structured file types

- Files with a **loose structure**, often used to store complex data relationships.
- **Examples:** `.json`, `.xml`

## Unstructured file types

- Files that do **not have a specific format** and often contain raw or multimedia data.
- **Examples:** `.png`, `.mp4`

## Big data and specialised file types

- Designed for **large-scale data**.
- **Example:** `.parquet`
