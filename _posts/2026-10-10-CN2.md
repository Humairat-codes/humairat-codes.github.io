Subnetting - the process of dividing a network into smaller networks
N1 -> S1,S2,S3,S4
Maintenance and administration become easier
Higher Security
But IT INCRERASES A STEP FOR IDENTIFICATION. (you usually gotta identify Network then host then port. But now, you gotta identify Network then subnet then host then port)
It also reduces some IP that could be allocated to a host but they get wasted for each subnet.
You require extra routers, switches, etc. 
You need a network Admnin to manage the subnets

How to make SUBNET?!
Its done by borrowing the bits from Host ID. can you imagine? 
say you got NID of 3 bits? How many networks you got? Yes, 8 networks! but for subnetting, you want more neworks so whha you do? You take some bit ftom host to increase the  network size. What do you get if you take 1 bit from host? Yes, 16 networks. That's the logic
so if you borrow 1 bit? you can get network * 2 networks (8 * 2 = 16)
